# Suggested commands (run from repo root)

- Build and run: `./run.sh [options]` (`set -e`: stops if gcc fails; forwards its arguments to `./branch_bench`)
- Build with warnings: `gcc -std=c99 -O2 -fno-tree-vectorize -fno-if-conversion -Wall -Wextra -pedantic -o branch_bench branch_bench.c`
- Clang build check: `clang -std=c99 -O2 -fno-vectorize -fno-slp-vectorize -Wall -Wextra -pedantic -o /tmp/bb branch_bench.c` (clang rejects `-fno-if-conversion` and makes Tests 1, 2 and 4-branch branchless; its timings are invalid, and `check_kernels.sh` must FAIL on it)
- Static analysis (mirrors SonarQube Cloud's path-sensitive C checks): `clang --analyze -std=c99 -Xclang -analyzer-werror <repo>/branch_bench.c` (CI form) — must print no warnings (writes a `.plist` in the cwd, not gitignored; run from a scratch dir)
- Markdown report: `./branch_bench -o report.md`; steadier numbers: `-n 5`; quick/small runs: `-t <N>`, `--size 64K --reps 2`. Help: `./branch_bench --help`. To add a machine to `RESULTS.md`, write the report to a separate file (`-o` truncates) and paste its `## <CPU>` section by hand under `# NEW RESULTS` (bare metal or WSL2) or `# VPS RESULTS` (cloud VMs), not at EOF; current entries use the defaults with `-n 6`.
- Kernel disassembly: `objdump -d --no-show-raw-insn branch_bench | awk '/<(sum_threshold|sum_branch|sum_branchless|count_decisions|dispatch_sequential|dispatch_random)(\.[^>]*)?>:/,/^$/'`. GCC folds `sum_threshold`/`sum_branch` into one body listed under either name; kernels may carry suffixes like `.constprop.0`.
- Perf counter permission: `cat /proc/sys/kernel/perf_event_paranoid` (≤ 2 needed).
- CI checks locally: `.github/scripts/check_kernels.sh ./branch_bench`; `.github/scripts/smoke_test.sh <binary> [work dir]` (exit 0 = all ok).
- Coverage with faked counters/sysfs: build `gcc -std=c99 -O0 --coverage -fno-tree-vectorize -fno-if-conversion -o branch_bench_cov branch_bench.c` and `gcc -shared -fPIC -o fake_perf.so .github/scripts/fake_perf.c -ldl` (no `-pedantic`: dlsym casts), run `.github/scripts/smoke_test.sh ./branch_bench_cov` (no-counter paths; real counters on bare metal), the same under `LD_PRELOAD=$PWD/fake_perf.so`, and the partial `FAKE_PERF_EVENTS` runs from the AGENTS.md block, then `gcov -b branch_bench_cov-branch_bench.gcda`. `FAKE_PERF_EVENTS=misses` (or `branches,cycles`, ...) opens only those counters. Build in a scratch dir: `.gcda`/`.gcno` land next to the binary.
- SonarQube Cloud (public project, no auth): issues `curl -s "https://sonarcloud.io/api/issues/search?componentKeys=juusolatva_branch_bench&resolved=false&ps=100"`; quality gate `.../api/qualitygates/project_status?projectKey=juusolatva_branch_bench`; per-line coverage `.../api/sources/lines?key=juusolatva_branch_bench:branch_bench.c&from=1&to=5000` (`lineHits`, `conditions`, `coveredConditions`, `isNew`).
- Full default run takes ~10 s (4M elements × 64 reps per variant); `-n N` takes about N+1 times as long.
